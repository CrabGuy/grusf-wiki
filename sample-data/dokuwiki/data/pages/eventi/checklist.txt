====== Checklist evento ======

Copia questa lista nella pagina del tuo evento e spunta man mano (sostituisci ''[ ]'' con ''[x]'').

===== Prima =====

  * [ ] Idea e budget approvati dal direttivo
  * [ ] Responsabile e squadra definiti
  * [ ] Data scelta (niente sessioni d'esame!)
  * [ ] Sala prenotata, conferma ricevuta
  * [ ] Permessi richiesti (se servono)
  * [ ] Locandina pronta
  * [ ] Post pubblicato sui social
  * [ ] Iscrizioni aperte / biglietti pronti
  * [ ] Lista della spesa / ordine catering
  * [ ] Turni dei volontari

===== Il giorno =====

  * [ ] Fondo cassa e ricevute
  * [ ] Kit pronto soccorso
  * [ ] Prolunghe, casse, microfono
  * [ ] Sacchi della spazzatura
  * [ ] Foto per i social (chiedi il consenso!)

===== Dopo =====

  * [ ] Sala pulita, chiavi restituite
  * [ ] Scontrini raccolti
  * [ ] Rimborsi fatti
  * [ ] Resoconto scritto nell'archivio
